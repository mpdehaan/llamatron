Code llamatron Uses ​

llamatron's built-in synths use other people's open work where it already models a sound well, only under licences compatible with llamatron's own. The implementations are llamatron's own, read from theirs, and a comment above every algorithm in the code names the work it follows and its licence.

Public Domain Music ​

llamatron's song wizard is built on music theory measured from public domain music, in files that carry no restricting licence of their own: scores and traditional tunes were read for how real melodies, harmonies and phrases behave, and only those measurements went into the program. None of the music is shipped with llamatron. Classical and traditional pieces from these collections also appear in some of the demos, such as the mashups. The song wizard will soon import downloaded corpus songs quickly, as patterns and scenes to start from.

Downloading the Corpus ​

The corpus is downloaded only by a person who wants it, for study, into output/corpus/, which git ignores; nothing downloaded is committed or passed on. From llamatron's top folder:

sh user_scripts/fetch_corpus.sh                 # asks collection by collection, with each one's size and terms
sh user_scripts/fetch_corpus.sh joplin thesession   # only the named collections

A collection is named by its folder in the table above, such as joplin or thesession. The script asks before each download. User Scripts describes the script.
