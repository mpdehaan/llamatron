# Installing llamatron

The installation instructions are in [docs/INSTALLING.md](docs/INSTALLING.md), which is also the Installing page of the [documentation website](https://mpdehaan.github.io/llamatron/INSTALLING). In short, from a fresh clone, run these from the project folder:

```
sh user_scripts/setup.sh
sh user_scripts/install_fluidsynth.sh
```
